# AI Web Design Tropes — Avoid All of These

## The Banned List

### Colors
- Purple-to-blue gradient hero backgrounds
- Dark navy + electric blue + white (generic SaaS dark mode)
- Teal + purple + pink gradient blobs floating in background
- Washed-out pastel palettes with no contrast

### Typography
- Inter as the only font with no personality
- Rounded corners + Inter = instant generic SaaS signal
- Giant centered serif heading over a gradient — feels like a template
- "UPPERCASE TRACKING" on every subheading with no reason

### Layout
- Perfectly symmetrical hero: image left, text right (or reversed), two CTA buttons
- 3-column feature grid with icon + title + 2 lines of text
- Centered text throughout the entire page
- "Bento grid" layouts (overdone as of 2024)
- Pricing table with three tiers side by side as the only section

### Visual effects
- Glassmorphism cards (frosted glass effect) — completely saturated
- Neomorphism (soft shadow inset buttons) — dead
- Floating cards with heavy drop shadows
- Mesh gradient backgrounds (the blurry colorful blob background)
- Aurora/northern lights background effect
- Noise texture overlay on gradient — slightly better but still overused
- Particle system that does nothing (random floating dots)

### Copy & Content
- "The Future of [Industry]" as a headline
- "Supercharge your workflow"
- "AI-powered" anything as the primary message
- Vague benefit headlines with no specificity
- Stock photo of laptop on desk or people in office smiling
- AI-generated illustrations (the pastel blob character style)
- "Trusted by 10,000+ teams" social proof row of logos

### Interactions
- Scroll fade-in on every single section (lazy)
- Hover: card lifts with shadow (overused)
- CTA button with gradient background + white text
- Loading spinner that's just a CSS border animation

---

## Replacements (what to do instead)

| Banned pattern | Fresh alternative |
|---------------|------------------|
| Gradient hero bg | Solid color, or raw texture, or full-bleed photography treated with duotone |
| Inter everywhere | DIN, Neue Haas Grotesk, ABC Diatype, Syne, Clash Display — or editorial serif like Canela |
| Symmetrical hero | Asymmetric grid, oversized type as structural element, text bleeding off screen |
| Feature icon grid | Alternating full-bleed sections, interactive demos, type-driven feature list |
| Glassmorphism cards | Hard borders, no radius, flat color blocks — or no cards at all |
| Gradient CTA button | Flat solid color button, or text-only with underline, or inverted block |
| Floating particle bg | Purposeful geometry that means something, or clean solid bg |
| "The Future of X" | Specific, concrete, unexpected first line — the more specific the better |
| Mesh gradient bg | Brand-specific color, real texture (paper grain, concrete), or pure black/white |
| Scroll fade-in everything | Scroll-driven 3D, text sliding on path, clip-path reveals, staggered type |
