# ACM-CEG EVENTS — COMPLETE ARCHITECTURAL EXPERIENCE REDESIGN

## IMPORTANT — READ THIS FIRST

This file is the COMPLETE and AUTHORITATIVE specification for the Events redesign.

The goal is to redesign the way the existing ACM-CEG event rooms are discovered, selected, entered and presented.

The existing event rooms are valuable 3D experiences and MUST be reused.

The new design introduces a premium architectural 3×3 presentation structure around those rooms.

Do NOT interpret the Events experience as:

- a 3×3 grid of cards
- nine poster thumbnails
- nine flat image tiles
- a generic website gallery
- nine rectangular buttons
- a simple CSS grid
- nine screenshots
- nine floating UI panels
- a portfolio card layout
- a dashboard
- a collection of mini website pages

THAT IS NOT THE DESIGN.

The intended experience is:

A LARGE, PREMIUM, PHYSICAL 3×3 ARCHITECTURAL STRUCTURE THAT HOLDS AND PRESENTS THE ACTUAL EXISTING 3D EVENT ROOMS.

Each of the nine compartments contains a real existing ACM-CEG event room.

The matrix is NOT the content.

The rooms ARE the content.

The matrix is the architectural/exhibition structure that frames, holds and presents those rooms.

The user should feel as though they are looking into nine miniature living environments inside one monumental ACM-CEG installation.

The overall experience should feel closer to:

- a cinematic digital exhibition
- a premium architectural installation
- a museum/gallery display
- an experimental interactive showcase
- a high-end digital studio experience

rather than a normal website UI.

Use the interaction language and editorial confidence of premium studio websites such as Basement Studio as inspiration for:

- typography
- whitespace
- hierarchy
- hover choreography
- directional motion
- editorial information presentation
- transitions
- visual confidence
- restraint

BUT DO NOT COPY Basement's:

- source code
- assets
- branding
- exact layouts
- exact typography
- exact animations
- project content
- visual identity

The final experience must clearly belong to ACM-CEG.

# 12. HOVER INTERACTION — THE PRIMARY MATRIX INTERACTION

Hovering a compartment should feel like activating a physical exhibition piece.

This should be one of the most visually polished interactions in the Events experience.

When the pointer enters a compartment:

The selected room becomes visually dominant.

The other eight rooms remain visible.

Do NOT black out the rest of the matrix.

Do NOT make the selected room explode in brightness.

Instead create controlled visual hierarchy.

The selected compartment may receive:

- slightly stronger illumination
- improved clarity
- subtle contrast enhancement
- restrained depth emphasis
- controlled local lighting
- subtle atmospheric separation
- slight depth/scale response where appropriate

The rest of the matrix should become quieter without disappearing.

Target approximately:

70–85% visual presence for the unselected environment,

depending on the scene.

The transition must interpolate smoothly.

No sudden opacity jumps.

No cheap glow.

No generic CSS hover.

No excessive bloom.
